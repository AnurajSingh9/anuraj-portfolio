Agent Evaluation Environment

RL environment for frontier coding agents: debug a stateful double-entry ledger where bugs only appear across accounting-period boundaries.

What I built

  • Agent tools: read/write files, run scenarios, submit
  • Three interacting state-dependent bugs (rollover, sign, rounding)
