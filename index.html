01

EvalForge

Python · FastAPI · Postgres · Redis · Docker

LLM eval · v1.1

Small platform to run LLM evals. You upload a JSONL set, it calls a model provider, scores the answers, and gives you metrics plus cost. Can export JSON, CSV, or HTML.

Includes

  • API key auth, rate limits
  • Redis/RQ workers
  • Exact, fuzzy, semantic, LLM-judge scoring
  • Token + rough USD cost on each run
  • Alembic, Prometheus, upload validation
GitHub v1.1.0

02

ledger-repair

Python · RL env · oracle grading

Agent eval env

Environment where an agent has to fix bugs in a double-entry ledger. The tricky part is the bugs only show up across period boundaries, so shallow patches fail.

Includes

  • Tools for read/write/run/submit
  • A few interacting bugs (rollover, sign, rounding)
  • 40 held-out scenarios + separate oracle
  • Checks for false accept / false reject
GitHub
