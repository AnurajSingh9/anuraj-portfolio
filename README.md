# Anuraj Singh — Portfolio

Personal site for selected work in AI evaluation, RL/agent environments, and production Python systems.

## Preview locally

```bash
cd ~/Projects/anuraj-portfolio
python3 -m http.server 5173
```

Open: http://localhost:5173

## Deploy on GitHub Pages

1. Create a public repo named `AnurajSingh9.github.io` **or** any repo and enable Pages on `main` / root.
2. Push these files.
3. In repo Settings → Pages → Deploy from branch `main` / `/ (root)`.

If using `AnurajSingh9.github.io`, the site will be at:

`https://anurajsingh9.github.io`
